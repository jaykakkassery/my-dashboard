📢 GET /campaigns API Details

The Campaigns endpoint is your "discovery" layer. It returns a list of active sales/promotions that you can display to users. Think of it as browsing the catalog of available deals.

📥 Request Parameters

Parameter Type Required? Description Example
language string Required BCP47 language code. Currently only en-US supported en-US
bookable_start date Optional Return campaigns bookable on or after this date 2026-04-01
bookable_end date Optional Return campaigns bookable on or before this date 2026-04-30
stay_start date Optional Return campaigns with stay window starting on/after this date 2026-07-01
stay_end date Optional Return campaigns with stay window ending on/before this date 2026-07-31
lifetime enum Optional Filter by campaign type: limited_time_offer or evergreen limited_time_offer
min_discount number Optional Only return campaigns with min discount at/above this value 20
blockout_dates boolean Optional true = only WITH blackouts, false = only WITHOUT blackouts false

📤 Response Parameters

Field Type Description How to Use in UI
id string Unique campaign identifier Pass to GET /promotions to fetch hotels in this campaign
name string Campaign name (e.g., "Summer Flash Sale 2026") Display as campaign title/heading
lifetime enum limited_time_offer or evergreen Show urgency badges: "Limited Time!" vs "Always On"
bookable_start date When users can start booking Calculate days until campaign opens
bookable_end date Last day users can book Countdown timer: "X days left to book!"
stay_start date Earliest check-in date Show travel window: "Stay Jun–Aug 2026"
stay_end date Latest check-out date Show travel window: "Stay Jun–Aug 2026"
min_discount number Lowest discount in campaign (e.g., 10) Show "From 10% off" messaging
max_discount number Highest discount in campaign (e.g., 60) Banner headline: "Up to 60% OFF!"
property_count number Number of participating hotels Show "4,820 hotels participating"
assets.thematic_images array Expedia-curated banner images Use as campaign card/banner background images
assets.destination_images array Destination photography Use in location-specific sections
assets.suggested_copy.headline string Pre-written headline Use as campaign card title
assets.suggested_copy.subheadline string Supporting text Use as campaign card subtitle/description
blockout_dates boolean Whether campaign has date restrictions Show warning: "Some dates may be excluded"

💡 Example Request

GET https://api.expediagroup.com/merchandising/v1/campaigns
  ?language=en-US
  &bookable_start=2026-03-11
  &bookable_end=2026-04-30
  &stay_start=2026-07-01
  &stay_end=2026-07-31
  &lifetime=limited_time_offer
  &min_discount=20
  &blockout_dates=false

🏨 GET /promotions API Details

After the user selects a campaign, you call the Promotions endpoint to get the actual hotel deals inside that campaign. This returns a ranked list of properties with ML-powered relevancy scoring.

📥 Request Parameters

Parameter Type Required? Description Example
language string Required BCP47 language code en-US
campaign_id string Required Campaign ID from GET /campaigns response CAMP_SUMMER2026
region_id string Optional Filter by city region (from Geography API). Only city-type regions work. 3000 (Paris)
min_star_rating number Optional Minimum hotel star rating (1-5) 3
min_discount number Optional Only return deals with discount at/above this value 20
sort_by enum Optional Ranking method: "promotion" (ML score) or "discount" (highest % first) promotion

📤 Response Parameters

Field Type Description How to Use in UI
property_id string Unique hotel identifier Pass to Property Content API and Availability API
deal_id string Unique promotion identifier Track which specific deal user clicked on
campaign_id string Parent campaign ID Reference back to campaign details
discount number Discount percentage for THIS hotel (e.g., 35) Display badge: "35% OFF"
score number ML relevancy score (1–10,000). Higher = more likely to convert Used for ranking. Not shown to user.
bookable_start date When this deal becomes bookable Show "Available starting Apr 1"
bookable_end date Last day to book this deal Countdown: "Book within X days"
stay_start date Earliest check-in date for this deal Date picker constraint
stay_end date Latest check-out date for this deal Date picker constraint
blackout_dates array Dates excluded from the deal Disable these dates in date picker. Show "Some dates excluded"
member_only boolean Whether deal requires membership Show "Members Only" badge. Hide if user not logged in.
mobile_only boolean Whether deal is mobile app exclusive Show "Mobile App Exclusive" badge
property_content_link string Tokenized URL to Property Content API Fetch hotel name, photos, amenities, address

💡 Example Request

GET https://api.expediagroup.com/merchandising/v1/promotions
  ?language=en-US
  &campaign_id=CAMP_SUMMER2026
  ®ion_id=3000
  &min_star_rating=3
  &min_discount=20
  &sort_by=promotion

🔗 Next Steps: Property Content Fetch

For each promotion, you call the tokenized property_content_link to get:

  • 🏨 Hotel name and address
  • 📸 Photos (hero images, room photos, amenity photos)
  • ⭐ Star rating and guest review scores
  • 🛎️ Amenities (WiFi, pool, parking, gym, etc.)
  • 📝 Description and key features

This data combines with the discount from promotions to create your hotel deal card UI.

🔗 How the Connection Works

Step 1: User clicks "View All Deals" on Summer Flash Sale campaign card

Step 2: System calls GET /promotions?campaign_id=CAMP_SUMMER2026&sort_by=promotion

Step 3: API returns ranked list of hotels with:

  • Property IDs, Deal IDs, Campaign ID
  • Specific discount for each hotel (35%, 42%, 28%)
  • ML scores for ranking (8450, 7820, 6340)
  • Deal restrictions (member-only flags, blackout dates)
  • Property content links to fetch hotel details

Step 4: For each hotel, fetch details using Property Content API via property_content_link

Step 5: Display ranked results with discount badges, ML scores, and CTAs to view availability/pricing
